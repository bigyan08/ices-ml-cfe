# NumPy Day 1 Assignment

## Tasks:

### 1. Array Creation Practice
Create the following arrays using different NumPy functions:
   - A 1D array with values from 10 to 50 with a step of 5 using `np.arange()`
   - A 3x3 identity matrix using `np.eye()`
   - A 4x5 array filled with the value 7 using `np.full()`
   - A 1D array with 8 evenly spaced values between 0 and 100 using `np.linspace()`

### 2. Practical Application
Simulate a simple gradebook system:
   - Create a 2D array representing 5 students and their marks in 4 subjects
   - Use random integers between 50 and 100
   - Calculate and print:
     - Average marks for each student
     - Average marks for each subject
     - Identify which student has the highest total marks
