# Seaborn Assignments

Complete the following assignment tasks to practice your Seaborn data visualization skills. Use the built-in Seaborn datasets for these exercises.

---

## **Assignment 1: Relationship Visualization with Scatter Plot**

**Dataset:** Use the `tips` dataset from Seaborn.

**Task:**
Create a scatter plot that visualizes the relationship between `total_bill` (x-axis) and `tip` (y-axis), with points colored by `sex` (Male/Female). Use the 'Set1' color palette.

**Requirements:**
- Load the tips dataset using `sns.load_dataset('tips')`
- Create a scatter plot with proper axis labels
- Add a descriptive title to your plot
- Use the 'Set1' palette for coloring by gender

**Expected Output:**
A scatter plot showing how tips relate to bill amounts, with different colors for male and female customers.

## **Assignment 2: Distribution Comparison with Box Plot**

**Dataset:** Use the `iris` dataset from Seaborn.

**Task:**
Create a box plot to compare the distribution of `sepal_length` across different `species` of iris flowers.

**Requirements:**
- Load the iris dataset using `sns.load_dataset('iris')`
- Create a box plot showing sepal_length for each species
- Add appropriate title and axis labels
- Use the 'pastel' color palette
- Set figure size to (10, 6) for better visibility

**Expected Output:**
A box plot showing the distribution and statistical summary of sepal lengths for three iris species (setosa, versicolor, virginica).
